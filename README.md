# AI 剧本工厂（开发版）

这是一个最小可行产品（MVP）项目，用于构建一套可长期投入生产的AI剧本工厂。

## 项目目标

- 支持：TXT 剧本读取
- 支持：OpenAI GPT /DeepSeek调用
- 支持：生成 Word 文档输出
- 支持：配置独立管理
- 支持：Prompt 独立管理
- 支持：日志独立管理

## 目录说明

- `config/`：存放所有可配置文件，例如API、模型、目录、日志配置
- `prompts/`：存放所有Prompt文本，Prompt独立管理
- `src/`：存放程序源代码，包含读取、AI调用、生成、导出、日志等模块
- `data/`：存放输入数据，例如示例TXT剧本、测试素材
- `output/`：存放生成结果，例如导出的Word文件
- `logs/`：存放运行日志文件
- `tests/`：存放后续测试代码
